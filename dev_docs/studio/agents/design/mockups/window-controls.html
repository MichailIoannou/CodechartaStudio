One top bar: window controls in the nav bar

With the setting Use CodeCharta's title bar on, the native title bar and frame go away and the nav bar is the only bar. Windows and macOS keep their real window buttons, drawn by the system into space the nav bar leaves free. On Linux, CodeCharta draws Breeze-style buttons itself. Shaded stripes mark the empty areas that move the window.
