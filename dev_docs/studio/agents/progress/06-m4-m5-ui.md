### C2 space priority
Label `min-w-16 truncate`, short SHA `shrink-0`. Below `2xl`: base-mode badge hidden in the chip and shown as the
first, non-clickable line of the caret menu ("Since the merge base" / "Tip vs tip", explanation as `title`); captions
hidden, side titles start "Base:" / "Head:". Below `xl`: stale badges show `fa-clock-rotate-left` + number (diverged
"3↓ 2↑"), full text stays in `title`. Below `lg`: PR badge icon only. Tailwind classes only.

**Finding (screenshots at 1920/1440/1200/1024, cc-dark):** before this change the side buttons (`min-w-0`) shrank below
their content and drew over their neighbours (the W1 icon, the swap button, the stale badge) at every width. Now the
side buttons keep their content (short SHA, label `min-w-16`), the chip's parts sit in an `overflow-hidden` wrapper
and the caret menu stays outside it, so nothing overlaps and Change… / Leave compare stay reachable. But the map slot
is still too narrow for the design's chip: at 1920 px with a PR, a stale badge and the base mode, the PR badge is cut
at the right edge; at 1024 px only the base side fits next to the project menu and W1. The four give-way steps are not
enough for the left half of the nav bar — the designer needs to decide what else leaves (e.g. the head label, the
swap button, or the chip taking a second row / the project menu shrinking further).

### Readings of the design (for the designer)
1. **gh/glab installed, but the core cannot list yet** (no `hosting.list*`): the segment shows only the number entry,
   no message (C7 has no state for it, and "no placeholder that reads coming soon" rules out a notice). With the
   current core this is what a user with a working `gh` sees.
2. **"Has hosting support"** is read as "`hosting.status` answers for the folder"; C7 says "the core can list hosting
   requests", which no core does yet — read literally, the segment (and the number entry, the only way to compare a PR
   now) would never show.
3. **NotInstalled** is taken from the desktop tools report (`gh`/`glab` row), since `HostingStatus` has no `cli` yet.
   `tooOld` / `failed` use C7's `Error` row with the tool's problem text.
4. Number-entry label: "Open pull request by number" / "Open merge request by number" (the mock-up's "Open PR / MR by
   number" read as either).
5. Open/Merged/All filter and the refresh button are left out while there are no rows; Refresh appears in the problem
   row ("refresh" action of C7's Error row).
6. Delta colours in the Changes rows: positive `text-success`, negative `text-error` (the default delta colours);
   inverted delta colours are not followed.
7. The Changes summary shows "+0 added · −0 removed · 0 changed" in the noDifferences form (no delta tree).
